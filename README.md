# SUKITORE - 40〜50代女性向けダイエット会員サイト

モバイル専用に最適化された40〜50代女性向けのダイエット会員サイトです。高級感のあるダークテーマと使いやすいUIで、ダイエット動画やブログ記事などのコンテンツを提供します。

## 特徴

- **モバイル最適化**: スマートフォン向けに特化したUIデザイン
- **合言葉によるアクセス制限**: 会員限定コンテンツを保護
- **ダークモードデザイン**: 黒・ネイビー・ゴールドを基調とした高級感のあるデザイン
- **コンテンツカテゴリ**: 新着・注目・人気コンテンツのセクション分け
- **管理者ページ**: コンテンツ投稿と管理機能

## 開発環境のセットアップ

1. 必要な依存関係をインストール:

```bash
npm install
```

2. 開発サーバーを起動:

```bash
npm start
```

アプリケーションは [http://localhost:3000](http://localhost:3000) で動作します。

## デフォルト認証情報

デモ環境では、以下の合言葉でログインできます:

- 合言葉: `sukitore2025`

## ファイル構造

```
src/
├── assets/         # CSS、画像などの静的ファイル
├── components/     # 再利用可能なUIコンポーネント
├── contexts/       # React Contextなどの状態管理
├── pages/          # ページコンポーネント
├── utils/          # ユーティリティ関数とモックデータ
└── hooks/          # カスタムReact Hooks
```
